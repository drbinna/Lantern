# Lantern

Landing page for Lantern, an autonomous aerial security response system: 360° camera stations that dispatch docked drones.

- `index.html` — static landing page (no build step)
- `docs/prd.md` — product requirements document
- `docs/infrastructure.md` — domain, hosting, deploys, hero video
- `docs/dns-records.md` — every DNS record on lanternaero.com and why it exists
- `docs/email.md` — how @lanternaero.com email works, adding/removing people, troubleshooting
- `tools/hero-render.html` — source scene for the hero video

Deployed on Vercel as a static site.
